# AffinityRoute 模块内部包结构契约

本文档固定 `sdk-api` 和 `registry-ratis` 之外各 Maven 模块的内部包结构和职责。`sdk-api` 的文件级结构见《Java 公共 API 契约》，`registry-ratis` 的文件级结构见《Raft 状态机与快照契约》，本文不重复。

约定：

- 粒度到包级。类名是建议而非强制，但包名、职责边界和依赖方向必须遵守。
- 所有包位于各模块根包之下（根包见主文档 4.3），不得跨模块声明同一 package。
- `internal` 子包及其下级属于实现细节，业务代码和其他模块不得依赖。
- 新增包必须先更新本文档，ArchUnit 测试按本文档校验依赖方向。

## 1. registry-protocol

```text
registry-protocol/src/main/java/cc/lvdaxianerplus/affinityroute/protocol/
├── dto/            REST 请求/响应 wire DTO，只含可序列化字段
├── event/          SSE 事件 DTO 和 schemaVersion
├── error/          统一错误码枚举和错误响应 DTO
└── codec/          DTO 与 JSON 的编解码，不含业务逻辑
```

- 不依赖 Spring、Ratis 和 HTTP 引擎，只表达线上协议。
- 字段增删遵守主文档 8.3 的兼容性规则。

## 2. lb-core

```text
lb-core/src/main/java/cc/lvdaxianerplus/affinityroute/loadbalancer/
├── hash/           规范哈希字节、加权 Rendezvous Hash
├── plan/           CandidateFilter、CandidatePlanner、CandidatePlan
├── concurrency/    加权最少并发评分和并发许可计数
└── affinity/       affinity key 提取 SPI 及 Header/Path/Query/JSON Pointer 实现
```

- 纯算法模块：不访问网络、磁盘和时钟之外的环境资源，不依赖 HTTP 引擎。
- 哈希、排序和评分实现必须通过《确定性算法与测试向量》的黄金向量。

## 3. lb-http-client

```text
lb-http-client/src/main/java/cc/lvdaxianerplus/affinityroute/http/
├── internal/
│   ├── retry/      RetryCoordinator、deadline 预算、退避
│   ├── execution/  AttemptExecutor、bulkhead、half-open 许可
│   ├── ejection/   LocalEjectionRegistry 和本地隔离状态机
│   ├── transport/  Apache HttpClient 5 Transport 和连接池
│   ├── classify/   ResultClassifier、异常到 FailureType 的映射
│   ├── observe/    CallObservation、指标埋点
│   └── log/        调用日志和 LogSanitizer
├── DefaultServiceHttpClient.java
└── DefaultLoadBalancerClient.java
```

- 只负责编排和治理，哈希与候选排序委托 `lb-core`。
- `internal` 下的类不进入公共 API，不受二进制兼容门禁约束，但不得被其他模块依赖。

## 4. registry-client

```text
registry-client/src/main/java/cc/lvdaxianerplus/affinityroute/client/
├── provider/       DefaultProviderClient、RegistrationHandle、续约调度、session token
├── discovery/      DefaultDiscoveryClient、不可变内存目录、SSE 订阅、revision 对账
├── snapshot/       磁盘快照读写、校验、损坏隔离
└── transport/      RegistrationTransport、CatalogTransport、端点切换与退避
```

- 通过 `transport` 适配控制面，不暴露 Ratis 类型，便于替换目录后端。
- 不实现负载算法；目录数据只以 `sdk-api` 不可变模型发布。

## 5. registry-server

```text
registry-server/src/main/java/cc/lvdaxianerplus/affinityroute/registry/server/
├── registration/   临时/静态实例应用服务
├── lease/          Leader 内存租约、切换宽限期
├── health/         主动 readiness 探测、UP/SUSPECT/DOWN/RECOVERING 判定
├── api/            REST Controller、DTO 映射、读一致性参数处理
├── events/         SSE 订阅管理、有界事件窗口、缺口检测
├── security/       身份、令牌、RBAC、密钥轮换
├── audit/          审计写入和有界索引查询
└── config/         配置绑定和启动装配
```

- 持久状态只能通过 `ConsensusStore` 读写，Controller 不直接操作状态机。
- 不依赖 Consumer 负载均衡实现。

## 6. console-api

```text
console-api/src/main/java/cc/lvdaxianerplus/affinityroute/console/
├── auth/           登录、会话 Cookie、CSRF、认证 SPI
├── rbac/           角色、权限判定、数据范围
├── catalog/        服务、实例查询和操作
├── clients/        SDK Client 心跳接收和在线目录
├── diagnostics/    只读路由模拟
├── cluster/        Leader、term、副本状态视图
├── identities/     身份管理和密钥轮换
├── approvals/      审批工作流和资源版本检查
├── audit/          控制台审计查询
├── settings/       namespace、group 和默认策略模板
└── events/         面向前端的资源失效事件
```

- 只读视图按一致性要求选择 `LINEARIZABLE` 或带元数据的 `STALE` 读。
- Leader 内存视图（Client 目录等）由 Follower 代理到 Leader，不用本地空数据冒充成功。

## 7. 其余模块

| 模块 | 包 | 职责 |
| --- | --- | --- |
| `registry-static` | `staticdiscovery/` | 固定 URL 配置加载为 `DiscoveryClient`，只读，不写控制面 |
| `lb-spring-boot-starter` | `starter/` | 自动配置、`affinityroute.*` 属性绑定、Provider 生命周期注册、健康指示器 |
| `observability-prometheus` | `observability/prometheus/` | Prometheus Query 代理、查询模板、标签白名单、降级处理 |
| `sdk-bundle` | 不适用 | 只聚合依赖，不含 Java 代码 |
