# GraphRAG复用探索

本目录用于沉淀 GraphRAG 在 RAG 检索、实体关系抽取、社区摘要和落地路径方面的独立探索结论。

该探索不绑定智能问答平台方案，可作为后续任意知识库、RAG 系统或问答产品升级到结构化知识检索的参考资料。

## 2. 核心结论

GraphRAG 的重点不是简单替换向量库或 Prompt，而是把普通 RAG 的“相似文本检索”升级为：

```text
文档
 -> 文本切块
 -> 实体关系抽取
 -> 知识图谱
 -> 社区聚类
 -> 社区摘要
 -> 局部检索 / 全局检索
```

---

## 3. 适用方向

- 私有知识库问答
- 多文档综合分析
- 实体关系密集型资料检索
- 需要主题、趋势、风险、共性总结的知识系统
- 需要证据链和可解释引用的 RAG 系统

---

## 4. 一句话定义

GraphRAG 复用探索关注如何把 RAG 从 chunk 相似度检索升级为实体图谱和社区摘要驱动的结构化知识检索。
