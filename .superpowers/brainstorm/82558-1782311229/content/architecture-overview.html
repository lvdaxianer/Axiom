平台分层架构

演示版先跑通最短闭环，最终版再补齐平台级治理与编排能力。

底座层 / 演示版 / 最终版
基础底座

日志与监控

用户日志、审核日志、知识录入日志、服务健康和模型健康。

模型管理

LLM、embedding、rerank、OCR、VL、parser 统一注册与路由。

权限与版本

知识库、模板、流程、应用的发布、回滚、可见范围控制。

演示版

1. 模板管理

维护几类模板和少量关键指标，形成约束性输入。

2. 知识库录入

上传模板文档，按指标生成候选图谱，人工审核后发布。

3. 文档校验

选择模板，对上传文档做结构、字号、标题、选填项校验。

4. 报告输出

输出哪里错了、为什么错了、依据是什么。

最终版

1. 平台治理

日志、监控、权限、审计、版本、告警、健康检查。

2. 知识治理

指标模板、知识库、图谱审核、证据链、chunk、权重和回溯。

3. 智能体编排

React Flow 画布、DSL、节点调试、发布、回滚和扩展节点。

4. 应用广场

统一发布审核智能体和知识问答应用，支持直接运行。

一期建议

先把“模板管理 + 指标管理 + 知识录入 + 文档校验 + 报告输出”做成可现场演示的闭环，再逐步补齐编排、问答和广场。
