关键调用链

BPMN 节点激活 → Flowable 创建 Agent Job → Agent Gateway 领取并创建幂等任务 → Pi 运行受限角色 Agent → 写入草稿和证据 → Gateway 回传结果 → Flowable 进入审批、回退或下一阶段。

边界原则：Flowable 决定“流程走哪一步”，DMN 决定“适用哪条业务规则”，Pi 决定“如何理解和生成内容”，事实库决定“项目当前到底是什么状态”。
